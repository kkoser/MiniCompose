# MiniCompose - A playground app for learning Compose internals

MiniCompose is a learning repository where we slowly re-build the fundamentals of Jetpack Compose from scratch in order to learn how things function under the hood. This project progressively implements more complex features (ex slot tables, skip groups, etc) in order to learn how things work, in addition to providing a basic Spring-based renderer and debugger to test code. This can also be used to experiment with new features for compose in a simplified codebase.

Feel free to play around or add things, and make sure to check out the `project_plan.md` to see where things are and what remains to do.
